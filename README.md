# tidy-up-game

Браузерный 3D-прототип cozy tidy-up (референс: TV Archive Tidy Up Together).

## Стек

Vite + TypeScript + Three.js

## Локальный запуск (после появления кода)

```bash
npm install
npm run dev
```

## Синхронизация дом ↔ офис

```bash
git pull    # перед работой
git push    # после commit
```

Подробности — в `AGENTS.md`.
